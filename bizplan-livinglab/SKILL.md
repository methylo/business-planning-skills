# 마을리빙랩 사업계획서 워크플로우

상주시 주민주도형 마을리빙랩 사업계획서를 정해진 문서구조에 맞춰 작성하는 6단계 프로세스.

## 참조 파일 (이 스킬이 위치한 디렉토리 기준)

| 파일 | 역할 | 로드 시점 |
|------|------|----------|
| `references/template.md` | 빈칸 템플릿 — [OOO] 플레이스홀더를 사용자 정보로 대체 | 각 Step 작성 시 해당 섹션 참조 |
| `references/sample-gongseong.md` | 공성면 영오리리빙랩 실제 사업계획서 — 문체·분량·구조의 기준 | 작성 패턴 확인이 필요할 때 참조 |

**작성 전 반드시 template.md를 읽는다.** sample-gongseong.md는 문체·분량 판단이 필요할 때 추가로 참조한다.

---

## 전체 흐름

```
Step 1: 일반현황 정리 → Step 2: 문제인식 작성 → Step 3: 실현가능성 작성 → Step 4: 이해관계자 정리 → Step 5: 확산·기대효과 → Step 6: 예산집행 계획
```

사용자의 상태에 따라 적절한 단계부터 시작한다.
- 마을·주제만 있음 → Step 1부터
- 문제인식까지 정리됨 → Step 3부터
- 전체 초안 있음 → 검토·수정 모드

### Step 간 전환 규칙

각 Step 완료 후, 다음 Step으로 넘어가기 전에 사용자 확인을 받는다.

| 전환 | 확인 방식 |
|------|----------|
| Step 1 → 2 | 일반현황(마을명, 팀명, 주제, 목표, 사업비)을 요약 제시하고 확정 여부 확인 |
| Step 2 → 3 | 문제인식(배경, 필요성, 현황분석, 주요목표)을 제시하고 수정 필요 여부 확인 |
| Step 3 → 4 | 실현가능성(아이디어, 실험계획, 추진일정, 평가항목)을 제시하고 확인 |
| Step 4 → 5 | 이해관계자(팀구성, 협력파트너, 이해관계자맵)를 제시하고 확인 |
| Step 5 → 6 | 확산전략(비즈니스모델, 가치창출, 로드맵, 기대효과)를 제시하고 확인 |

사용자가 "끝까지 진행해줘" 또는 "한 번에 해줘"라고 요청한 경우, 확인 없이 연속 진행한다.

## 문서구조 규칙

### 번호체계

template.md의 구조를 그대로 따른다. 요약:

```
□ 일반현황 (표 형식)
1. 리빙랩 문제인식
  1-1. → 1) → ❍ → -
  1-2. → 1) → ❍ → -
  1-3. → 1) → ❍
2. 실현가능성
  2-1. → 1)
  2-2. → 1)~4)
3. 이해관계자 및 지원 협력기관
  3-1. → ❍ → -
  3-2. → 표 + ◆이해관계자맵
4. 확산 및 기대효과
  4-1. → 1)~3)
  4-2. → 1)~2)
5. 예산집행 계획 (표 형식)
```

### 본문 서식 규칙

| 요소 | 표기법 | 용례 |
|------|--------|------|
| 대항목 기호 | ❍ | ❍지역생산물 소비촉진을 통한 경제 활성화 |
| 소항목 기호 | - | -텃밭을 가꾸는 마을 주민들이 대다수로... |
| 표 참조 | [표 N] | [표 1] 공성면 인구 변화 추이 |
| 그림 참조 | [그림 N] | [그림 1] 공성면 노동인구 분포 현황 |
| 출처 표기 | (출처 : ) | (출처 : 2024년 공성면 통계연보) |
| 강조 | 볼드 | **가치제안**, **경쟁우위**, **수혜자** |

[표 N]과 [그림 N]은 문서 전체에서 순서대로 번호를 매기며, 반드시 출처를 명시한다.

## 문체 기준

- 종결어미: '~함', '~임' 체 (사업계획서 서술체)
- 문장은 간결한 서술형. 한 문장에 하나의 사실 또는 계획
- 주어를 생략하지 않는다. 주체가 명확히 드러나도록 작성
- 감정적 표현, 감탄형 문장 사용하지 않음

### 사업계획서 용어 규칙

| 분류 | 용어 |
|------|------|
| 사업 구조 | 리빙랩, 실험, 프로토타입, 현장실험, 확산하기 |
| 참여 주체 | 연구원, 팀장, 팀원, 책임멘토, 이해관계자그룹 |
| 인구·지역 | 관계인구, 체류인구, 정주인구, 지역소멸위기 |
| 평가 | 정량지표, 정성지표, 만족도 조사, 구글폼 조사 |
| 사업화 | 잉여농산물, 소득화, 마을기업, 셀러, 가치제안 |
| 비즈니스 모델 | 고객군, 수혜자, 경쟁우위, 핵심지표, 고객세그먼트 |
| 계획 단위 | 단기(1~2년), 중장기(3년~), 년중계획, 월별계획 |

### 금지 요소

아래 표현은 사용하지 않으며, 샘플(sample-gongseong.md)에 해당 표현이 남아 있더라도 새 사업계획서 작성 시에는 이 금지 규칙을 우선 적용한다.

- 과장형 형용사: "혁신적인", "획기적인", "완벽한", "창의적인" 등
- 모호한 부사: "매우", "쉽게", "빠르게" 등
- 추측 표현: "~할 수 있습니다" → "~함", "~을 목표로 함"으로 대체
- 추상적 목표: 구체적 수치·시기·방법을 반드시 명시
- AI 흔적 표현: "효율적으로", "체계적으로", "종합적으로" 등

## Step별 작성 지침

각 Step에서 template.md의 해당 섹션을 참조하여, [OOO] 부분을 사용자 정보로 대체한다. 문체·분량 판단이 필요하면 sample-gongseong.md의 동일 섹션을 추가 참조한다.

### Step 1: 일반현황 정리

#### 정보 수집 방식

사용자에게 아래 입력 양식을 제시하고, 한 번에 붙여넣어 제출하도록 안내한다.
항목이 많으므로 질문을 나열하지 않고, 복사-붙여넣기 가능한 양식을 제공한다.

```
[사업계획서 기본정보 입력양식]

■ 기본정보
마을명:
팀명:
사업기간: YYYY.M.D. ~ YYYY.M.D.
총 사업비:          원
보조금 비율:        %

■ 리빙랩 주제
해결하려는 지역 문제:
접근 방법(아이디어명):

■ 목표(산출물) — 연도별로 기재
·
·
·

■ 팀 구성
팀장 이름/담당업무/보유역량:
팀원1 이름/담당업무/보유역량:
팀원2 이름/담당업무/보유역량:
(추가 팀원이 있으면 계속 기재)

■ 마을 현황 (있는 만큼 기재)
인구수/연령분포/노동인구:
위치/교통편:
주요 자원(토지, 시설, 인적 자원):
```

사용자가 양식 전체를 채우지 못한 경우, 빈 항목만 추가 질문한다.
필수 항목(마을명, 팀명, 주제, 목표, 팀원, 사업비, 사업기간)이 모두 확보되면 Step 2로 전환한다.

→ template.md의 "사업비 교부신청서" + "일반현황" 섹션 참조

### Step 2: 문제인식 작성

1-1(주제, 선정배경, 필요성) + 1-2(실험대상지역, 실험대상자) + 1-3(주요목표)

핵심: 인구 데이터(과거→현재 비교), 노동인구 분포, 토지 현황을 수치로 제시하여 사업의 당위성을 확보한다.

→ template.md의 "1. 리빙랩 문제인식" 섹션 참조

### Step 3: 실현가능성 작성

2-1(아이디어 경과과정, 사전준비 이력) + 2-2(장소, 실험내용, 추진일정, 평가항목)

핵심: 리빙랩 6단계(깊이공감→문제정의→아이디어발굴→프로토타입실험→현장실험→확산하기) 경과를 시간순으로 서술. 정성/정량 지표 표 작성.

**교육과정 단계 유연성**: 마을마다 이수한 교육과정 단계가 다를 수 있다. 이수한 단계까지만 기술하고, 이수하지 않은 단계는 생략한다. 교육과정을 이수하지 않은 마을은 마을의 기존 행사·사업 경험을 "사전준비 이력"으로 대체한다.

→ template.md의 "2. 실현가능성" 섹션 참조

### Step 4: 이해관계자 정리

3-1(팀 역량) + 3-2(이해관계자 현황표, 그룹 역량, 이해관계자맵)

핵심: 이해관계자맵은 동심원 구조(핵심자원→관계인→협력→고객)로 구성하고, 활동목표/환경/문제해결을 함께 기술.

→ template.md의 "3. 이해관계자 및 지원 협력기관" 섹션 참조

### Step 5: 확산·기대효과 작성

4-1(비즈니스모델-린캔버스, 가치창출-고객세그먼트, 로드맵-년중/월별) + 4-2(단기/중장기 기대효과)

핵심: 린캔버스 5항목(가치제안, 경쟁우위, 수혜자, 고객군, 핵심지표)을 볼드 처리. 중장기 효과에 벤치마킹 사례 제시.

→ template.md의 "4. 확산 및 기대효과" 섹션 참조

### Step 6: 예산집행 계획

비목별 예산표 작성.

핵심 규칙:
- 산출근거: "단가×수량=합계" 형식 필수
- 비율 제한: 급량비 10%이내, 재료비 60%이내
- 강사비: 등급과 시간 구분 산출, 원천세 포함 표기
- 재료비: 품목·규격·수량 구체적 기재

**비목 유연성**: template.md에 제시된 8개 비목(활동비, 급량비, 재료비, 홍보비, 강사비, 체험/견학비, 임차비, 합계)은 기본 구조이다. 마을 사업 특성에 따라 불필요한 비목은 제외하고, 필요한 비목(예: 보험료, 인건비, 운반비, 인쇄비 등)은 추가한다. 비목을 추가·삭제하더라도 비율 제한(급량비 10%이내, 재료비 60%이내)과 합계 일치는 반드시 준수한다.

→ template.md의 "5. 예산집행 계획" 섹션 참조

## 최종 출력

모든 Step 완료 후, 전체 사업계획서를 하나의 문서로 통합하여 .docx 파일로 생성한다.

### 문서 구성 순서

1. 사업비 교부신청서 (표지)
2. 일반현황 (Step 1)
3. 첨부 목록
4. 1. 리빙랩 문제인식 (Step 2)
5. 2. 실현가능성 (Step 3)
6. 3. 이해관계자 및 지원 협력기관 (Step 4)
7. 4. 확산 및 기대효과 (Step 5)
8. 5. 예산집행 계획 (Step 6)

### .docx 생성 시 적용 규칙

- 제목: 굵게, 14pt
- 소제목(1., 2., 3., 4., 5.): 굵게, 12pt
- 세부항목(1-1., 2-1. 등): 굵게, 11pt
- 본문: 10pt, 줄간격 1.5
- 표: 전체 테두리, 헤더 행 배경색(연회색)
- 페이지 번호: 하단 중앙, "- N -" 형식
