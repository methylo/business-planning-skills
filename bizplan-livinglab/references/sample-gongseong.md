# 가상 마을리빙랩 사업계획서 예시

이 문서는 구조·문체·분량 확인을 위한 가상 예시다. 실제 마을·기관·주소·예산을 재현하지 않는다. 실제 작성에서는 해당 연도 공고문과 사용자가 제공한 자료를 사용한다.

## 일반현황

- 마을명: 해솔마을
- 팀명: 해솔 생활실험팀
- 주제: 유휴공간을 활용한 주민 공동판매 실험
- 총사업비: 20,000,000원(가상)
- 목표: 주민 판매 실험 3회, 참여자 만족도 조사, 운영모델 작성

## 1. 문제인식

해솔마을은 고령 인구 증가와 소규모 생산물의 판매 채널 부족을 함께 겪고 있음. 최근 인구와 소득 자료는 해당 지자체 통계연보에서 확인해 표로 제시하며, 원문을 확인하지 못한 수치는 `[근거 필요]`로 남김.

## 2. 실현가능성

1. 주민 인터뷰로 판매 품목과 참여 조건을 확인함.
2. 마을 공용공간에서 소규모 판매 실험을 진행함.
3. 방문자 수, 참여 판매자 수, 판매액, 만족도를 측정함.
4. 결과를 바탕으로 다음 실험의 품목·시간·홍보 방법을 조정함.

## 3. 이해관계자

- 주민팀: 품목 준비와 현장 운영
- 마을조직: 장소와 참여자 조정
- 지역기관: 공고 범위에서 행정 지원
- 방문자: 구매와 만족도 조사 참여

실제 기관명과 개인명은 사용자 확인 후 작성함.

## 4. 확산·기대효과

단기에는 실험 3회의 데이터를 확보하고, 중기에는 주민이 운영 가능한 판매 규칙과 역할표를 완성함. 매출이나 방문자 목표는 근거 없이 확대하지 않음.

## 5. 예산

산식 검증 예시는 `examples/budget-example.json`을 사용함. 실제 비목·한도·강사비는 해당 연도 공식 예산편성지침을 확인한 뒤 적용함.
